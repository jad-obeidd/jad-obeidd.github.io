Case file · Computer Science project

VoteVision

An online voting platform for polls and candidate elections, with live result charts, shareable poll links, an admin dashboard and duplicate-vote prevention.

Role
Computer Science project
Stack
PHP 8, MySQL, JavaScript, Bootstrap, jQuery, Chart.js, Tesseract OCR
Code

The problem

Creating elections and polls, managing candidates, casting votes and viewing results online.

What I did

  1. Built the platform in PHP and MySQL with Bootstrap, jQuery and Chart.js.
  2. Prevented duplicate votes for registered users.
  3. Added live result charts, poll expiration countdowns and shareable poll links.
  4. Added optional identity-document processing with Tesseract OCR.
  5. Prepared the repository for sharing: the database file is a sanitized schema with no real users or voting records.

Key features

Accounts
Registration, login and profile management.
Elections
Election events, candidate lists and candidates.
Public polls
Polls with configurable choices, expiration countdowns and shareable links.
Live results
Results with chart visualization.
One vote each
Duplicate-vote prevention for registered users.
Responsive interface
Built with Bootstrap.

A demonstration project for education. It has not been independently security-audited and is not meant for high-stakes elections.
