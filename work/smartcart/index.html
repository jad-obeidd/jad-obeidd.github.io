Case file · Built solo

SmartCart

An AI shopping assistant: type "taco night for 4" and get a priced list. It understands "healthy snacks under $5", recommends products and streams live price changes.

Role
Built solo
Stack
React, Bootstrap, Node.js, Express, MongoDB, OpenAI API, JWT, Server-Sent Events
Live demoCode

The problem

Turning a plain sentence into a priced shopping list, and searching a product catalog in plain language.

What I did

  1. Built the React client and the Express + MongoDB API.
  2. Used the OpenAI API for list generation, natural-language search and recommendations, with a rule-based fallback so the app runs fully without an API key.
  3. Streamed price changes to the browser over Server-Sent Events.
  4. Added JWT authentication with bcrypt-hashed passwords; lists are private to their owner.
  5. Wrote API tests with an in-memory MongoDB.
  6. Made a static demo build that answers every API route in the browser with the server’s own rule-based code.

Key features

Smart list generation
A prompt and the product catalog go to the OpenAI API; each returned item is matched to a catalog product, so the list has prices and an estimated total.
Natural-language search
The query becomes structured filters (keywords, category, price range), then products are ranked by relevance and price.
Personalized recommendations
Suggests products that complement the items in your lists, with a short reason for each.
Real-time price tracking
A background job updates prices and keeps a price history per product; list totals and price badges update live. The price feed is simulated.
JWT authentication
Register and log in with bcrypt-hashed passwords; lists are private to their owner.

Outcome

A live demo runs entirely in the browser with the same rule-based engine: no server, database or API key.

The API tests cover auth, natural-language search (with and without a mocked OpenAI client), list generation, item updates, ownership checks, recommendations and the price tracker.
